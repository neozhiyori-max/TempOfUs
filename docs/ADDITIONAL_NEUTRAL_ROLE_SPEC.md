# 追加第三陣営20役職の実装仕様

すべての能力要求・変身・投票修正・勝利判定はホストが確定し、参加者へ状態同期する。画面暗転、壁抜け、外見変更、観戦表示などの視覚効果はローカル表示のみとし、実体プレイヤーやネットワーク参加者を複製しない。

| 役職 | ボタン | 主要状態 | 勝利判定／失敗条件 |
| --- | --- | --- | --- |
| 神（ゴッド） | 全知 | 全役職公開の使用状態 | 自身が生存し、全タスク完了時に勝利。直接キル不可。 |
| ジェスター | なし | なし | 会議で追放された時点で単独勝利。既存実装を維持。 |
| ジャッカル | キル / 陣営勧誘 | サイドキックID | インポスター全滅かつジャッカル側人数がクルー以上。 |
| ヴァンパイア | 吸血 | 噛みつき対象・死亡時刻 | 自身以外を排除して生存。既存実装を維持。 |
| シュレディンガーの猫 | 陣営同調 | 同調後の陣営 | 最初のキル／追放者へ同調し、その陣営の勝利に従う。未同調の終了は敗北。 |
| ゾンビ | 感染キル | 親ゾンビID・子ゾンビ集合 | 生存者を全員ゾンビ陣営化。インポスターにキルされると敗北。 |
| アパシー | タスク放棄 | 後追い勝利可否 | インポスター／ジャッカルへの直接キル時に後追い勝利。追放は敗北。 |
| アドボケイト | 買収 | 次会議の投票権剥奪対象 | インポスター勝利時に生存していれば共同勝利。 |
| ピエロ | 錯乱ガス | 操作反転対象・終了時刻 | インポスターまたはジャッカル勝利時に生存なら共同勝利。キル死は敗北。 |
| アルソニスト | ガソリン噴霧 / 点火 | 注油済み対象集合 | 生存者全員へ注油後、点火に成功すれば勝利。会議で一部注油を失う。 |
| テロリスト | 自爆 | 自爆結果 | 自爆でインポスターまたはジャッカルを1人以上巻き込み死亡すれば勝利。 |
| ハゲタカ | 死体回収 | 回収数・必要数 | 指定数の死体を回収すれば勝利。 |
| コレクター | アイテム強奪 | 窃盗数・必要数 | 終了時に総タスク25%以上相当を盗めば勝利。 |
| ガーディアン | 絶対防御 | 保護対象・残り防御数 | 保護対象が生存したままクルー勝利なら勝利。対象死亡で敗北。 |
| ファナティック | 狂信 | 崇拝対象 | 対象インポスター勝利時に生存なら共同勝利。対象追放時は死亡。 |
| シーフ | スキン強奪 | なりすまし対象・擬態陣営 | キル相手の外見・陣営勝利条件に一時的に従う。 |
| ゴーストハンター | 幽霊捕獲 | 捕獲済みゴースト集合 | 発生済みゴーストをすべて捕獲。捕獲ごとにクルータスク総量を減少。 |
| バウンサー | 強制退場 | ロック回数・対象ドア | 生存しつつドアロックを10回成功。インポスター対象時は相手CDをリセット。 |
| スペクテイター | 観戦モード | 観戦終了時刻 | 任意主要陣営が勝利するまで生存。観戦中は本体が無防備。 |
| アサシン | 暗殺 | 暗殺対象／残り使用回数 | 指定対象役職を会議外で暗殺すれば勝利。実行時に位置を公開。 |

## 共通状態モデル

追加第三陣営は以下の共通データで表現する。

| 状態 | 使用する役職例 |
| --- | --- |
| 期限付き効果（`EffectExpiresAt`） | 錯乱ガス、観戦、同調演出、外見擬態、壁抜け |
| 対象ID（`EffectTargets`） | 保護、崇拝、買収、感染、暗殺、サイドキック |
| 二次対象（`SecondaryEffectTargetId`） | 投票奪取、対になった対象、陣営変化の起点 |
| 実績数／目標数 | ハゲタカ、コレクター、バウンサー、ゴーストハンター |
| 陣営変化 | 猫、シーフ、ゾンビ、サイドキック |
| 特殊勝利フラグ | 神、テロリスト、アサシン、アルソニスト、アパシー |

勝利判定は、既存の `VictoryResult` に特殊勝利・共同勝利の参加者IDを追加して行う。会議専用能力（買収、推測、票偽装、陣営同調）はMeetingHudパッチからホストへ要求し、通常の能力ボタンと同じくホスト検証後に状態同期する。

## 実装進捗（開発中）

| 機能群 | 現在の状態 | 実機確認対象 |
| --- | --- | --- |
| 役職抽選・ON/OFF・人数・出現率 | 第三陣営の追加17役職を含め登録済み | 設定一覧のページ送り、抽選結果 |
| 能力HUD | 標準AbilityButtonへ役職名・クールダウン・対象可否を同期 | ガソリン噴霧／点火、死体回収、全知 |
| 清掃・捕食・回収 | エンジン上の死体削除とDeadBodyの非表示同期を実装 | 清掃後に通報できないこと |
| 会議能力 | マッドゲッサー、アドボケイト、ディセプター用の会議ボタンと投票対象フックを実装 | 会議ボタン、推測選択、買収対象 |
| 特殊勝利 | ジャッカル側、ゾンビ、ハゲタカ、アルソニスト、テロリストなどを段階実装 | 終了画面・チャットの勝利ラベル |

会議中の推測は、**会議能力ボタンを押して表示される推測役職を確認し、その後に投票パネルから対象を選ぶ**操作とする。マッドゲッサーは推測に失敗すると自爆する。すべての最終判定・死亡・役職変化はホストが確定し、状態同期RPCを経由して参加者へ反映する。
