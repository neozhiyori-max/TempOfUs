# tempMOD — SNR主基盤への再構築設計

**基準:** SuperNewRoles `713c98779e14000479f7578a28705264645f07e5`（GPL-3.0）  
**現行tempMOD基準:** `dc6c532`  
**目的:** 独自の役職エンジンを再び作るのではなく、SuperNewRoles（SNR）の実績ある役職・設定・会議・同期構造を主基盤にする。ただし、接続経路や外部サービスに関わるSNR機能は初期版へ含めない。

## 採用方式

tempMODは、SNRの**完全な配布物を名前だけ変えて再配布する方式**ではなく、SNRの役職システムをフォークした派生MODとして構成します。SNRのソースを固定コミットで記録し、役職・設定・会議・同期の土台をSNRの実装に揃えます。tempMOD独自の役職エンジン、独自RPCプロトコル、独自役職設定モデルは再導入しません。

> 役職が未選択でもSNR由来の設定・同期・会議基盤が起動できることを先に確認し、その後に役職を**上流のSNR実装単位**で有効化します。役職ごとに独自簡略化した処理を新設しません。

## 構成の責務

| 層 | 採用元 | tempMODでの扱い |
|---|---|---|
| プラグインエントリポイント | SNR `main.cs` | tempMODのGUID・名称・ロゴへ置換し、SNRの段階的初期化構造を採用します。 |
| 役職管理 | SNR `CustomRoleManager`、`Roles` | SNRの役職基底クラス・Ability・状態遷移を主基盤とします。 |
| 設定 | SNR `CustomOptions`、`CustomOptionManager` | SNRの設定登録・同期・ページ構造を主基盤とします。 |
| 同期 | SNR `CustomRPCManager`、`SyncVersion` | SNRのホスト権限、RPC識別、バージョン整合を主基盤とします。 |
| 会議 | SNRの会議パッチ・Ability | SNRの会議開始・投票・終了・HUD復旧の状態遷移を主基盤とします。 |
| 起動画面 | tempMOD `TitleLogoPresenter` | TempOfUsロゴを最初のタイトル画面だけに表示します。 |
| 配布更新 | tempMOD `GitHubAutoUpdater` | tempMOD GitHub Releasesのみを更新元にします。 |
| 管理者検証 | tempMOD `MatchControlRuntime` | 終了抑止と廃村のみを保持します。 |

## 初期版で有効にしないSNR機能

| 機能 | 無効化理由 |
|---|---|
| SNR独自サーバ・地域追加・マッチメイキング | Among Us標準の接続経路を変更しないためです。 |
| 外部API、解析、ゲーム内リクエスト | 明示的な同意なしに外部通信を発生させないためです。 |
| SNR独自更新・告知・画像取得 | tempMODのGitHub Releases更新に一本化するためです。 |
| カスタムコスメ、トロフィー、実績 | 役職基盤の起動検証とは独立しており、初期安定化の対象外のためです。 |
| CPUアフィニティ変更 | ユーザー端末のプロセス設定を変更しないためです。 |
| SuperHostRoles固有のサーバ依存機能 | 対象外です。通常のMOD導入クライアント同士の同期を優先します。 |
| テストダミー、プレイヤー複製、参加者追加 | ネットワーク安全性のため恒久的に禁止します。 |

## 実装ゲート

| ゲート | 合格条件 |
|---|---|
| SNRコンパイル | .NET 8 SDKをコンパイラに使用し、`net6.0`ターゲットでエラー0件。 |
| 最小起動 | SNR由来の外部通信・独自サーバ・全役職を無効にした状態でタイトル、ロビー、開始、会議、終了までエラーなし。 |
| 同期基盤 | 全導入クライアントでバージョン整合とホスト権限を確認し、未認識RPCを誤読しない。 |
| 役職追加 | 1役職ごとに、SNR上流コード、設定、HUD、会議、死亡、勝利、同期、セルフテスト、実機確認をそろえる。 |
| 実機配置 | 公開版・管理者版ビルド、差分書式、安全監査のすべてを通過後、ゲーム終了中だけにDLLを置換する。 |

## 最初に有効化する役職

最初の有効化候補は**シェリフ**です。SNRにも同名役職があり、直接キル、誤射自爆、キル上限、第三陣営への可否といった受入条件を小さく閉じられます。設定・Ability・キル判定・会議後の状態維持というSNR基盤の重要経路を、少人数で安全に検証できます。

## ライセンスと表示

tempMODはGPL-3.0を維持します。SNRコードを取り込むコミットには、固定コミット、元ファイル、変更ファイル、変更目的を`NOTICE.md`と移植台帳へ記録します。SNR由来でないtempMODのロゴ・更新・管理者検証機能も区別して記録します。
