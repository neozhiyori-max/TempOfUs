# tempMOD 役職ガイド

この文書は、tempMODに登録されている役職とゲーム内での操作方法をまとめた日本語ガイドです。役職の抽選、能力の最終判定、死亡・死体・勝利は**ホストが確定し、MOD導入済み参加者へ同期**されます。オンラインで遊ぶ場合、ホストと参加者は全員同じバージョンのtempMODを導入してください。

> **実装状況の読み方:** 「基本実装済み」は役職割当・設定・HUDラベル・ホスト判定の対象です。「検証中」は役職の登録と基本同期は済んでいますが、外見変化、画面演出、会議UIなどの一部表現を継続検証している項目です。

## 設定と基本操作

ホストはロビーのゲーム設定から **tempMOD設定** を開きます。陣営を選択すると役職一覧が表示され、各役職の左側にある **`切替`** を一度押すだけでON/OFFを変更できます。右側の **`設定`** では、人数、10%刻みの出現率、役職ごとの追加設定を変更できます。役職が多い陣営は `前へ` / `次へ` でページを切り替えます。

| 場面 | 操作 |
| --- | --- |
| ロビー | `tempMOD設定` → 陣営 → 役職行の `切替` で即ON/OFF、`設定` で人数・出現率・詳細設定 |
| 通常ゲーム | 右下の役職専用ボタンをクリック、または **Fキー**。対象が必要な能力は近くのプレイヤーまたは死体を選びます。 |
| 会議 | 市長は自動2票。マッドゲッサーは**会議中だけ**各プレイヤー横の `推測` を押し、クルー役職一覧から選択します。 |
| 開始直後 | 自分だけに、役職名と説明がチャットへ自動表示されます。 |

## 既知の検証対象

追加役職のうち「検証中」の役職は、能力の役職登録、抽選、設定、ラベル表示、ホスト側の状態管理・同期を先に実装しています。一方、変身の見た目、壁抜け、入力反転、ダミー・ホログラム、部屋の強制移動、監視設備の偽表示など、Among Us本体の描画・移動・会議UIを直接扱う演出は段階的に実機検証しています。動作に違和感や不具合があれば、役職名・マップ・操作・スクリーンショット／動画を添えて報告してください。

## ゲーム終了抑止と廃村

公開版・管理者検証版の両方で、ホストはロビーの **tempMOD設定** を開き、**ゲーム制御** の `ゲームを終了しない` をON/OFFできます。ONの間は通常の勝利条件による試合終了を抑止するため、役職能力の検証に使えます。通常のマルチプレイではOFFを推奨します。

また、ホストは両版共通で **Shift + L + Enter** を押すと、進行中の試合を廃村できます。この操作はホストだけに反応し、ロビーおよび終了画面では動作しません。
