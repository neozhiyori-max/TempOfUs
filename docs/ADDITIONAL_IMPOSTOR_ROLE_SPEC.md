# 追加インポスター20役職の実装仕様

この文書は、追加役職をホスト権限のルールエンジン、参加者同期、HUD、会議処理へ段階的に実装するための仕様です。すべての能力要求はホストが検証し、クライアントは確定状態を表示します。

| 役職 | HUDボタン | ホスト確定の主要状態 | 能力とペナルティ |
| --- | --- | --- | --- |
| クリーナー | 清掃 | 清掃対象死体、清掃完了時刻 | 近くの死体を数秒かけて消去する。処理中は移動不能。完了後の死体は通報不可。 |
| マッドゲッサー | 推測 | 会議中の予想対象・役職 | 会議中にクルー役職を予想し、正解なら対象を死亡、不正解なら自爆する。 |
| モーフィング | 遺伝子採取 / 変身 | DNA対象、変身終了時刻 | 対象近くでDNAを採取後、その姿へ変身する。終了時に短時間移動不能。 |
| マリオネット | 糸操作 | 操作役・犠牲者 | クルーを操り別クルーをキルさせ、犠牲者の死体を残さない。 |
| ボマー | 爆弾設置 | 爆弾対象、爆発時刻 | 対象へ時限爆弾を設置し、爆発時に周囲の生存者を巻き込む。通常直接キルは不可。 |
| スパイ | 盗聴 | 盗聴中状態 | クルーの会話とタスク進捗を表示する。キルクールダウンは長い。 |
| トラッパー | 罠設置 | 罠位置、罠終了時刻 | 入口へ罠を一つだけ置き、通過したクルーを一定時間スタンさせる。 |
| ブラックアウト | 目隠し | 効果中心、効果終了時刻 | 範囲内クルーを一時的に暗転させる。効果中は本人も減速する。 |
| ファントム | 幽体化 | 幽体化終了時刻 | 半透明・壁抜け状態へ移行し、効果中はキル不可。 |
| バウンティハンター | ターゲット確認 | 指定ターゲット | 指定ターゲットのキル後は次回キルCDを0、他者キルはCDを倍にする。 |
| ヴァンパイアロード | 従者蘇生 | ミニオンID | キルした対象をキル不可のミニオンとして復帰させる。 |
| ハッカー | 偽装工作 | ハック対象端末、終了時刻 | 端末前で監視設備情報を偽装する。発動中は端末から離れられない。 |
| イリュージョニスト | 分身生成 | ホログラム位置・有効状態 | 任意地点に攻撃可能なホログラムを一体だけ設置する。 |
| サイレンサー | 口封じ | 沈黙対象、直前対象 | 指定対象を次の会議で沈黙させる。同一対象への連続使用は不可。 |
| グラトニー | 捕食 | 捕食中死体、完了時刻 | キル後の死体を消す。捕食中に通報された場合は即時通報へ移行する。 |
| タイムシーフ | 時間強奪 | タスク時間減少量 | キル成功ごとにクルー側の制限時間を減らす。最初のキルCDは長い。 |
| ディセプター | 票偽装 | 一回限りの偽装投票対象 | 会議で最多得票者と別の対象を追放する。ゲーム中一回のみ。 |
| ネクロマンサー | 死体操縦 | 操縦対象死体、移動先 | 死体を遠隔移動して別プレイヤーの近くへ置く。 |
| ウィッチ | 呪詛リンク | リンク対象二名、詠唱開始 | 近くにいる二人をリンクし、片方の死亡時にもう片方も死亡させる。 |
| アルケミスト | 錬金ステルス | 透明死体、透明終了時刻 | キル時の死体を一時透明にし、解除時に全員へ通知音を出す。 |

## 共通方針

> 実体プレイヤー、PlayerControl、ネットワーク参加者を複製して能力対象を作らない。幻影・死体可視性・画面効果は、既存のゲームオブジェクトか明示的なローカル表示専用オブジェクトに限る。

能力は `AbilityRequest` としてホストへ送信する。ホストは役職、対象の生死、距離、会議状態、クールダウン、使用回数を検証し、確定結果だけを状態同期する。ボタンは標準AbilityButtonを再利用し、役職ごとにラベルを差し替える。

## 実装順

第1段階では、役職カタログ、設定、状態同期、キル／死体／会議の規則を追加する。第2段階では、清掃、爆弾、リンク、捕食、従者、透明死体などの確定効果を実装する。第3段階で変身、画面暗転、幻影、端末偽装、会議専用選択UIなどを接続する。
