# 役職参照比較・安定化監査台帳

## 目的

この台帳は、tempMODの設定対象 **56役職** と、抽選で派生するサイドキック・子ゾンビ・ラバーズを、SuperNewRoles（SNR）を第一参照元として比較するための記録である。SNRに直接対応がない場合は、Nebula、Town Of Us Reworked（TOU）、TheOtherRoles（TOR）の順で同等実装を照合する。

> 上流実装に対応する役職は、能力の説明だけでなく、**発動条件、クールダウン、対象判定、会議開始・終了、死亡、追放、勝利条件、名前表示、ホスト同期**までを一単位として比較する。対応元がない役職だけを独自補完として残す。

## 監査判定

| 判定 | 意味 |
|---|---|
| `A: 回帰確認済み` | 上流の主要状態遷移を移植済みで、セルフテストを通過している。 |
| `B: 実装済み・差分監査中` | 基本能力はあるが、設定・会議・表示・同期に上流との差分が残る。 |
| `C: 重大差分` | 仕様の核が上流と異なる。上流準拠へ優先修正する。 |
| `D: 対応元なし` | 対応する公開役職が見つからず、独自要件として安全な共通基盤だけで扱う。 |

## 最優先の修正順

1. **神（ゴッド）**：タスク完了・生存の単独勝利経路は実装済み。実タスク完了から終了画面・結果表示まで確認する。
2. **シュレディンガーの猫**：被キル時の自動陣営変化は移植済み。追放時クルー化・非特定第三陣営への設定をSNRオプションへ追加する。
3. **会議・同期の共通経路**：会議終了後の暗転、HUD復元、カスタムRPCのログを実機で継続確認する。
4. **アルソニスト**：SNRの注油チャネル・表示・点火ボタン状態へ照合する。
5. **会議役職**：市長、アドボケイト、ディセプター、マッドゲッサーの票・追放処理を同じ会議状態機械へ集約する。
6. **死体役職**：アンダーテイカー、クリーナー、ハゲタカ、グラトニー、ネクロマンサーのBodyState処理を上流と比較する。
