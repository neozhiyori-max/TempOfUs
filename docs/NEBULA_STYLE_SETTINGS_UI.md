# tempMOD設定パネル：Nebula on the Ship参考UI仕様

## 参照範囲

Nebula on the Shipの参考動画から、設定画面の**情報設計と操作導線**を参照する。tempMODではコード、素材、名称、アイコンを転載せず、独自のタイトル・配色・役職データで実装する。

## レイアウト

設定画面は三分割構成とする。左列はカテゴリ選択、中央列は役職一覧、右列は選択した役職の詳細設定である。上部には `tempMOD 設定` タイトルと閉じる操作、下部には `左: ON/OFF`、`右: 出現率 +1`、`カーソル: 参考元` の操作ガイドを表示する。

| 列 | 内容 | 操作 |
|---|---|---|
| 左 | 一般、クルー、インポスター、第三陣営、モディファイア | カテゴリを選択して中央リストを切替 |
| 中央 | 役職名、短い能力説明、現在の有効状態 | 行を選択して右側の詳細を切替、独立スクロール |
| 右 | 役職名、陣営、ON/OFF、出現率、主要能力値、参考元 | `-` で有効状態切替、`+` で出現率増加、参照表記を確認 |

## 適用する操作仕様

1. 初期選択は `クルー` カテゴリの `シェリフ` とする。
2. カテゴリを変えると中央一覧だけを更新し、一覧の先頭役職を自動選択する。
3. 役職を選ぶと右列に `ON/OFF`、`出現率`、能力説明、参考元を表示する。
4. 役職行へのホバーまたは詳細右列では、`参考: SuperNewRoles / Nebula on the Ship` を表示する。
5. 設定を変更した時点でBepInEx設定ファイルへ保存する。試合の役職抽選はホスト設定だけを使う。
