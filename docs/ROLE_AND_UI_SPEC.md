# tempMOD 役職・タイトル画面仕様

**MOD正式名:** `tempMOD`  
**表示ロゴ:** `TempOfUs`  
**初期版:** `0.1.0`  
**対象:** PC版 Among Us（BepInEx IL2CPP環境）

## 1. 設計原則

tempMODでは、役職をゲーム開始時にホストが割り当て、**判定に影響する全ての操作をホスト権限で確定**する。能力の発動要求、対象、発動時刻だけをクライアントから送信し、キル、死亡、ワープ、シールド、呪い、勝利といった状態更新はホストが検証して全員へ同期する。この方式により、クライアントごとの差異や不正な状態更新を抑える。

全役職は、`RoleDefinition`（静的な定義）、`RoleState`（ゲーム中の動的状態）、`AbilityRequest`（能力発動要求）、`RoleRpc`（ホスト確定結果）に分離する。会議、緊急会議、ゲーム終了時には一時的な矢印、足跡、遠隔バイタル画面、操作支配、霊魂会話を必ず解除する。

## 2. 陣営と役職一覧

| 陣営 | 役職 | 主能力 | 初期設定値 | 実装上の要点 |
|---|---|---|---:|---|
| クルー | シェリフ | インポスターまたは第三陣営を直接キル | CD 25秒 | クルーを対象にした場合はキルを無効化し、シェリフ本人を死亡させる。 |
| クルー | ドクター | 通報可能な死体の死亡推定時刻を秒表示 | 常時 | 死体生成時のネットワーク時刻を保存し、発見者の画面だけに `死亡から n 秒` と表示する。 |
| クルー | マッドサイエンティスト | 任意地点から一時的にバイタル画面を開く | 5秒 / CD 45秒 | 通常端末の操作状態とは分離し、使用中に会議・死亡した場合は強制終了する。 |
| クルー | トラッカー | 指定1名への方角矢印を表示 | 10秒 / CD 30秒 | 対象選択画面と画面端矢印を持ち、対象の死亡・会議開始で解除する。 |
| クルー | タイムトラベラー | 数秒前の自分の位置へワープ | 巻戻し 5秒 / CD 35秒 | 0.25秒間隔の位置履歴をホストが保管し、通行不可位置は直近の有効位置へ補正する。 |
| クルー | シーア | 死亡プレイヤーの霊魂と短時間会話 | 8秒 / CD 40秒 | 死者のみと送受信できる一時チャネルを作り、生存者・会議中には使用不可とする。 |
| クルー | バリアニック | 他者1名に1回限りのキル防止バリアを付与 | CD 35秒 | シールド消費時はキルを無効化し、対象・キラー双方へ視覚的な結果を同期する。 |
| クルー | ライトワーカー | 停電中も自分の視界を維持 | 常時 | ローカル視界計算の暗闇係数だけを上書きし、停電修理や他者の視界は変えない。 |
| クルー | インベスティゲーター | 他人の色付き足跡を追跡 | 残留 6秒 | 移動履歴から一定間隔で足跡イベントを生成し、本人以外の色で表示する。 |
| クルー | 市長 | 会議投票を自動で2票として扱う | 2票 | 投票確定時の重みをホストが加算し、結果画面は通常の匿名投票設定を尊重する。 |
| インポスター | ニンジャ | 周囲に見聞きされないキル | CD 40秒 | キル対象・死亡同期は通常どおり行い、近傍クライアントに対する演出と音だけを抑制する。 |
| インポスター | ウォーロック | 対象に呪いをかけ、接触した他者を自動キルさせる | 呪い 12秒 / CD 30秒 | 呪われた者が別プレイヤーへ近接した瞬間、ホストが対象をキラー扱いで死亡させる。自己接触・会議中は除外する。 |
| インポスター | マフィア | ノーコストでサボタージュを連続発動 | CD 0秒 | 能力ボタンをサボタージュ一覧に置換し、直接キル要求は常に拒否する。サボタージュ自体のゲーム内条件は残す。 |
| インポスター | パペッティア | 対象1名を短時間だけ強制操作 | 5秒 / CD 35秒 | 入力はホストが対象へ中継する。発動者は操作中に停止し、対象のキル・会議・死亡で終了する。 |
| インポスター | イレイザー | キル相手の役職開示を抑止 | 常時 | 死亡レコードに `RoleErased` を記録し、役職開示UI・死体関連表示を汎用表記に置換する。 |
| インポスター | アンダーテイカー | 死体を運搬して別地点へ移す | 移動速度 70% | 運搬状態は死体を非表示にし、プレイヤーに追従させる。ベントへ入る前に近傍へ安全に配置して終了する。 |
| 第三陣営 | ジェスター | 会議で追放されると単独勝利 | 常時 | 投票で追放された時点を最優先で判定し、通常の生存数・タスク勝利より先にゲームを終了する。 |
| 第三陣営 | ジャッカル | 全陣営を直接キルできる | CD 30秒 | クルー・インポスター・第三陣営をキル可能とし、生存者が本人のみになったとき勝利する。 |
| 第三陣営 | ヴァンパイア | 噛みつきによる時間差キル | 遅延 10秒 / CD 30秒 | `BiteExpiresAt` を同期し、時刻到達時に対象が生存ならホストが死亡させる。会議中のタイマー扱いは設定で選択可能にする。 |
| 第三陣営 | ラバーズ | 2名が最後まで生存するとペア勝利 | 常時 | 開始時に別々の2人を抽選し、一方の死亡を契機に他方を後追い死亡させる。2人だけが生存した時点で共同勝利する。 |

## 3. 勝利判定の優先順位

| 優先度 | 条件 | 結果 |
|---:|---|---|
| 1 | ジェスターが会議投票により追放された | ジェスター単独勝利。 |
| 2 | ラバーズの2名のみが生存 | ラバーズ共同勝利。 |
| 3 | ジャッカルのみが生存 | ジャッカル勝利。 |
| 4 | 致命的サボタージュが未修理で終了 | インポスター陣営勝利。 |
| 5 | 生存インポスター数が生存クルー数以上 | インポスター陣営勝利。 |
| 6 | クルーが全タスクを完了、またはインポスターが全滅 | クルー陣営勝利。 |

ジャッカル、ラバーズ、ジェスターが他役職と重複するかは、設定で切り替える。初期設定では、ジャッカルとジェスターは固有役職、ラバーズは任意陣営に重複付与できるモディファイアとして扱う。

## 4. 共通イベントと同期

| イベント | 発信者 | ホスト検証 | 全員への確定同期 |
|---|---|---|---|
| 役職割当 | ホスト | 人数、重複不可、設定値 | 役職ID、モディファイア、能力初期化 |
| 能力要求 | 発動者 | 生存、陣営、対象、距離、クールダウン、会議状態 | 成功／失敗、CD、継続状態 |
| キル要求 | 発動者 | キル可能性、シールド、役職固有制約 | 死亡、死体生成、演出種別、後処理 |
| 会議開始 | ゲーム | 状態を強制解除 | 票重み、役職開示マスク、ジェスター判定 |
| 会議終了 | ホスト | 追放・勝利を先に判定 | 生存状態、次フェーズ状態 |
| ラウンド終了 | ホスト | 勝利優先順位 | 勝利陣営、勝者、役職サマリー |

## 5. タイトル画面ロゴ

タイトル画面の `MainMenuManager` 初期化後に、既存の中央ニュースパネルを複製して `tempMOD_TitlePanel` として生成する。ロゴスプライトには `assets/tempofus_logo.png` を埋め込み、黒い背景、星の装飾、下部の `tempMOD v0.1.0` というテキストを表示する。標準のニュース表示を削除せず、パネルが見つからないゲーム版では画面中央に代替パネルを出すフォールバックを実装する。

ロゴ画像は受領済みの原稿を加工したユーザー提供素材であり、`tempofus_logo_source.png` は編集用、`tempofus_logo.png` は実行時埋込用とする。tempMODの名称とロゴ表示名が異なる現在の構成では、画面下部のバージョン表記で正式名称を明示する。

## 6. 実装完了の判定

実装完了とするには、少なくともホスト・参加者の双方で役職割当、能力クールダウン、キル、会議、勝利判定、ラウンド終了後の初期化が一致している必要がある。ゲーム本体のバージョンによってIL2CPPのインターオプ型名が変化するため、最終ビルドにはユーザーが共有する `BepInEx/core` と `BepInEx/interop` のDLL群を参照する。
